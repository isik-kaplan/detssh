# Wordlists

`eff_large_wordlist.txt` is the EFF's large wordlist for dice-generated
passphrases, byte for byte as published at
<https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt>
(SHA-256 `addd35536511597a02fa0a9ff1e5284677b8883b83e986e43f15a3db996b903e`,
pinned by `tests/test_diceware.py`). 7776 words, one per roll of five dice.
